# Ambient Backgrounds

A collection of animated canvas background effects built with vanilla JavaScript and the HTML5 Canvas API. Each effect uses simplex noise and particle systems to create smooth, ambient visuals.

## Effects

- **Drift** - Noise driven particle flow with glowing trails
- **Circuit** - Procedural pipe trails that turn and weave across the screen
- **Nebula** - Soft, drifting color blobs with heavy blur
- **Vortex** - Rotating particles spiraling toward the center
- **Borealis** - Vertical light rays inspired by the northern lights

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server with hot reload |
| `npm run build` | Production build to `dist/` |
| `npm start` | Dev server with auto open |

## Tech

- Webpack 4
- Babel 7
- Simplex Noise
- HTML5 Canvas (dual buffer rendering)
